# Workflow de Desenvolvimento com IA

## O que é Workflow?

Workflow é um fluxo de trabalho organizado.

Na programação, workflow significa definir uma sequência lógica de etapas para desenvolver uma funcionalidade, evitando bagunça, confusão e mudanças aleatórias no projeto.

Exemplo simples:

1. Entender o problema
2. Planejar a funcionalidade
3. Criar Model
4. Criar Controller
5. Criar View
6. Testar
7. Melhorar

---

## Para que serve?

Usar workflow ajuda a:

- organizar o desenvolvimento
- evitar erros
- entender o que precisa ser feito
- dividir problemas grandes em pequenas partes
- usar IA de forma mais inteligente
- trabalhar de forma parecida com projetos reais do mercado

---

# Workflow Oficial — Projeto HelpDeskMVC

## Etapa 1 — Entender a funcionalidade

Antes de programar:

- o que será criado?
- qual problema resolve?
- qual objetivo da funcionalidade?

Exemplo:

"Adicionar tela para abrir novos chamados."

---

## Etapa 2 — Planejar antes de codar

Antes de pedir código para IA:

- quais arquivos serão alterados?
- quais Models serão usados?
- qual Controller será alterado?
- precisará criar View?
- haverá formulário?
- haverá validação?

---

## Etapa 3 — Implementar em pequenas partes

Nunca pedir tudo de uma vez.

Errado:

"Crie um sistema completo."

Correto:

1. Criar action GET Create
2. Criar formulário
3. Criar action POST
4. Validar ModelState
5. Redirecionar para Index

---

## Etapa 4 — Revisar o código

Após gerar código com IA:

- ler o código
- entender o que foi feito
- testar
- verificar erros
- verificar organização

A IA ajuda.
O aluno continua sendo responsável por entender.

---

## Etapa 5 — Testar a funcionalidade

Sempre testar:

- navegação
- formulário
- validações
- erros
- fluxo completo

---

## Etapa 6 — Melhorar e refatorar

Após funcionar:

- melhorar nomes
- organizar código
- remover duplicações
- melhorar visual
- adicionar comentários importantes

---

# Como usar IA corretamente no projeto

## A IA NÃO substitui o aluno

A IA é:

- ferramenta de apoio
- assistente
- acelerador de aprendizado

O aluno precisa:
- entender o código
- saber explicar
- conseguir modificar
- conseguir testar

---

# Exemplo de uso correto da IA

## Exemplo ruim

"Faça meu sistema inteiro."

---

## Exemplo bom

"Crie a action GET Create no ChamadosController para abrir a tela de cadastro de chamados."

---

## Outro exemplo bom

"Explique o que esse código faz linha por linha."

---

# Regra principal

## Pequenas tarefas → melhores resultados

Quanto mais específico for o pedido:
- melhor o código
- mais fácil entender
- menor chance de erro
